# WaneIris

A simple WaneIris optimizer for real time data processing.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/WaneIris.git`
2. `cd WaneIris`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure WaneIris, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
